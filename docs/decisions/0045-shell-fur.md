# 0045. Shell fur: extra materials on the skinned renderer, alpha-tested, three distance levels

- Status: accepted
- Date: 2026-11-02

## Context
- The local Jolly skin (docs/art/jolly-demo.md) is a plush character. On `Jolly/Character/NubiSkin` it rendered as a smooth, matte pink body: the user called it bleak. The art pass already bakes shell-fur maps for it (§1b: length, density, tip and AO; comb flow; a tiling strand-height noise).
- The character is a `SkinnedMeshRenderer` (22 bones, 13 blendshapes), animated every frame, about 26k triangles. Quest 3 renders single-pass instanced stereo with 4× MSAA at 72 Hz; `perf_idle` before this change: 72.0 fps, p95 frame 13.888 ms, 11 draw calls, 27,040 triangles (2026-11-01, `--character jolly`).
- Passthrough is composited under the eye buffer by its alpha, and the character's materials write alpha = environment visibility so real objects and hands hide it (ADR-0024). Anything that lowers the alpha over the body lets the room show through it.

## Decision
- **Shader** `Jolly/Character/ShellFur` (`Content/Rendering/Shaders/ShellFur.shader`): one material is the opaque base layer (the skin, root-shaded by fur length and AO). With the `_FUR_SHELL` keyword and a `_ShellHeight` h in (0, 1] the same material is a shell: the vertex moves out along the normal by h × length, sags with gravity and is combed along the flow map by h² × length, swings with the body's inertia and a slow idle sway; the fragment keeps the strands of the noise taller than h^`_StrandTaper` (fewer where density is low) with `clip`: a taper of 1 makes cone strands that read as bristles up close, 2 keeps each strand wide most of its height, which reads as plush. `_SkinStrands` prints the same noise onto the base layer (one more texture read there), so short or stretched patches such as a raised arm's armpit look like pile instead of bare skin. Albedo, fur maps and lighting (wrapped Lambert, SH ambient, a rim that grows towards the tips) are read per vertex for shells, so a shell fragment is one texture read, one clip and the occlusion test. It uses `EnvironmentOcclusion.hlsl` like NubiSkin and outputs `(colour × visible, visible)`: a surviving strand writes alpha 1 unless a real object is in front. SRP Batcher compatible; stereo instancing macros as in NubiSkin. `DepthOnly` clips the same way.
- **Drawing the shells**: `ShellFur` (`Runtime/Character/Fur/`) appends the shell materials to the renderer's material array. Unity draws every material past the last submesh on that submesh again, from the vertices it already skinned this frame, so the shells follow bones and blendshapes with no extra skinning, mesh or bake. One draw per shell, SRP-batched (same shader variant, per-material CBUFFER). The fur therefore has to be the renderer's **last submesh**; `ShellFur` refuses and logs otherwise. The Jolly build puts its gloss faces and slot first (`put_fur_last` in `tools/blender/build_jolly.py`: Unity numbers submeshes by the first face of each material, not by slot).
- **Level of detail**: the base material says how many shells to draw near, mid and far and from which distance (`_ShellCount*`, `_ShellDistance*`); `ShellFur` builds all three shell sets once, and `NubiCharacterController.LateUpdate` picks one by the user's head distance with a 0.15 m band (`ShellFurLod`), swapping only the material array. Each set spreads its shells over the full length, so a far level is coarser, not shorter.
- **Shell order**: shells sit in the AlphaTest queue (2450+), outermost first, after every opaque so the skin keeps its early depth.
- **Motion**: `FurInertia` is a damped spring (2.5 Hz, damping ratio 0.45) on the root bone's position: the tips keep their place when the body moves, lag by at most one fur length, and swing back. The lag is set on the drawn shells every frame (no property blocks, which would leave the SRP Batcher).
- **Jolly's material** (local, git-ignored, `M_Jolly_Fur`): 16 / 10 / 6 shells from 1.6 / 3.2 m, length 0.042 m (the recipe's 0.024 read short against the reference photo's long plush pile), droop 0.5, comb 0.75, strand fullness 2, skin strands 0.5, strand tiling 22, bald below length 0.008. Bald below 0.12 had left a bare notch under the chin and bare, streaky armpits on `Wave`; tiling 26 moiréd into diagonal hatching at the far level. Data maps are imported linear, the noise with Repeat. Shell counts are unchanged by this tuning.

## Consequences
- Every furry renderer costs one draw and one pass over its fur triangles per shell. Jolly on Quest 3, release build, user about 1.2 m away (near level, 16 shells), self-test `perf_idle`: 72.0 fps, p95 frame 13.889 ms (before: 72.0, 13.888), draw calls 11 → 26, SetPass 9 → 10, triangles 27k → 436k (over the 300k scene row of `docs/perf/README.md`, which assumed one draw per character). The compositor's app GPU time at idle, freshly rebooted headset, 30 s per run, GPU level 2: 3.8 ms (34 %) with the NubiSkin build of 2026-11-01 → 8.9 and 9.1 ms (81–82 %) with fur, 0 stale frames in either; the installed build re-measured 8.8 ms (80 %), 1 stale frame in 1,961. Within the frame, but most of the GPU at its default level.
- The plush tuning (strand fullness 2, skin strands, length 0.042 m) costs nothing measurable: the same idle run, back to back on one boot, 30 VrApi seconds each, app GPU time 9.51 ms before and 9.34 ms after, 72 fps, 1 stale frame in 30 s.
- Moving the shells' occlusion test from the fragment to the vertex did not change that GPU time (9.0 and 9.4 ms), so it stays per pixel: the shell cost is the fill of 16 alpha-tested layers, not the test. Fill grows with the inverse square of the distance, so a user crouching close to the character costs more than this idle measurement; that case is unmeasured.
- Clipped strands are aliased within a shell (MSAA smooths only geometry edges); mipmapped noise softens them with distance. Up close at grazing angles the shell layers read as steps at the silhouette.
- Any character can have fur by giving its last submesh a `ShellFur` material and the maps; nothing in the definition changes. A character without one is untouched (an empty list per frame).
- The fur ignores the main light's shadows like NubiSkin; rim and AO carry the depth.

## Alternatives
- **Alpha-to-coverage** for soft strand edges. It writes the coverage alpha into the eye buffer too, so strand edges over the body would lower its alpha below 1 and show passthrough through the character. Rejected.
- **Bake the skinned mesh N times (`BakeMesh`)**, or a pre-baked shell mesh. CPU skinning of 16 × 16k vertices per frame, or a mesh 16× larger skinned every frame. Rejected for cost.
- **One instanced draw from the skinned vertex buffer** (`GetVertexBuffer` + `RenderPrimitivesIndexed`, shell index from the instance ID). One draw instead of 16, but it bypasses culling and the SRP Batcher, needs its own stereo instancing (the instance ID is already split between eyes in single-pass instanced) and hand-written timing against skinning. Kept as the next step if the draw count ever matters.
- **A renderer feature issuing `DrawRenderer` per shell.** Same draw count as extra materials, plus a render-graph pass to maintain. Rejected.
- **Fins or a geometry shader.** Fins need silhouette edges found every frame; geometry shaders are slow on tile-based mobile GPUs. Rejected.
